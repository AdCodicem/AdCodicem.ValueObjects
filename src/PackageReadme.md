# AdCodicem.ValueObjects

This package is part of AdCodicem.ValueObjects, single-value DDD value objects for .NET 10 and later: a `readonly
partial struct` marked `[ValueObject<T>]` gets its whole implementation from a source generator, and crosses every
boundary as its underlying type. What this package adds is in its description above.

It works with the main package, which holds the generator:

```sh
dotnet add package AdCodicem.ValueObjects
```
