## Remarks

<code>[KnownValue("France", "FR")]</code> on a <code>CountryCode</code> value object generates <code>CountryCode.France</code>,
adds the value to <code>CountryCode.KnownValues</code>, and surfaces it in the OpenAPI schema. Combined with
<xref href="AdCodicem.ValueObjects.Annotations.ValueSetKind.Closed" data-throw-if-not-resolved="false"></xref> the declared values also become the validation rule of the type.

compile time.
